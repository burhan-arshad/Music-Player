# Music Clone

A simple and responsive music streaming website clone built using **HTML5, CSS3, and vanilla JavaScript**.

## Features

* Music player interface
* Play and pause controls
* Song selection
* Interactive progress bar
* Volume control
* Responsive layout
* Vanilla JavaScript functionality

## Technologies

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
Music-Player/
│
├── index.html
├── style.css
├── script.js
└── assets/
    ├── images/
    └── music/
```

## Project Purpose

This project was created as a **frontend development project** to practice building interactive web interfaces using core web technologies without relying on frameworks or external libraries.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/burhan-arshad/Music-Player.git
```

Open the project folder and launch `index.html` in your browser.

No installation or dependencies are required.
